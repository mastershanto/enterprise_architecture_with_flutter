## 📍 API Endpoints

### Save Address
```
POST https://nanaobiriyeboah.thewarriors.team/api/address/save
Content-Type: application/json

{
  "address_line1": "Dhaka",
  "city": "Dhaka",
  "state": "Dhaka",
  "postal_code": "12345",
  "country": "bangladesh",
  "label": "home"
}
```

**Response (201)**:
```json
{
  "status": true,
  "message": "Address saved successfully",
  "data": {
    "id": 43,
    "user_id": 3,
    "address_line1": "Dhaka",
    ...
  },
  "code": 201
}
```

### Delete Address
```
DELETE https://nanaobiriyeboah.thewarriors.team/api/address/43
```

**Response (200)**:
```json
{
  "status": true,
  "message": "Address deleted successfully",
  "data": null,
  "code": 200
}
```

## 🚀 Usage Examples

### Save Address
```dart
addressProvider.saveAddress(
  addressLine1: 'Dhaka',
  addressLine2: 'Apartment 5B',
  city: 'Dhaka',
  state: 'Dhaka',
  postalCode: '12345',
  country: 'Bangladesh',
  latitude: 23.8103,
  longitude: 90.4125,
  label: 'home',
);
```

### Delete Address
```dart
addressProvider.deleteAddress(
  id: addressProvider.state.savedAddress!.id,
);
```

### Check State
```dart
if (addressProvider.state.isLoading) {
  // Show loading
}
if (addressProvider.state.error != null) {
  // Show error
}

  // Show saved address
}
```
